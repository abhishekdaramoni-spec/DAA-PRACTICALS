SUMMARY:-
In this practical, I implemented and analyzed five different sorting algorithms in C++: Bubble Sort, Selection Sort, Insertion Sort, Quick Sort, and Merge Sort. Each program accepts an array of integers from the user, sorts the elements in ascending order, displays the sorted output, measures the execution time using the C++ <chrono> library, and reports the corresponding time and space complexities. 

Through this implementation, I observed the working principles of each algorithm:
•	Bubble Sort repeatedly compares adjacent elements and swaps them until the array becomes sorted. An optimized version was used to stop early if the array was already sorted. 
•	Selection Sort repeatedly selects the smallest element from the unsorted portion and places it at its correct position. 
•	Insertion Sort gradually builds a sorted sequence by inserting each element into its appropriate location in the already sorted part of the array. 
•	Quick Sort follows the divide-and-conquer approach by selecting a pivot element, partitioning the array around it, and recursively sorting the resulting subarrays. 
•	Merge Sort also uses the divide-and-conquer technique by recursively dividing the array into smaller parts and merging them back in sorted order. 
The execution time recorded for each algorithm provided a practical comparison of their efficiency, while the theoretical time and space complexities helped explain their performance for different input sizes.
Conclusion:-
This practical helped me understand how different sorting algorithms work and where they are best used. By implementing each algorithm and comparing their execution time, time complexity, and space complexity, I learned that the choice of sorting algorithm has a direct impact on performance. Bubble Sort, Selection Sort, and Insertion Sort are simple to understand and work well for small datasets, while Quick Sort and Merge Sort are more suitable for larger datasets because they sort data more efficiently. Overall, this practical improved my understanding of sorting techniques and gave me practical experience in analysing and selecting the most appropriate sorting algorithm for different situations.
