# Prim's Algorithm

## Summary
Prim's Algorithm is a greedy algorithm used to find the Minimum Spanning Tree (MST) of a weighted graph. It uses key, parent, and visited arrays to select the minimum-weight edges.

## Graph
[A, B, 2]
[A, D, 6]
[B, C, 3]
[B, D, 8]
[B, E, 5]
[C, E, 7]
[D, E, 9]

## Result
MST Edges:
A - B : 2
B - C : 3
B - E : 5
A - D : 6

Total Weight = 16

## Conclusion
Prim's Algorithm successfully finds the Minimum Spanning Tree by selecting the minimum-weight edges. The total weight of the MST is 16.
