## Summary

BFS (Breadth-First Search) and DFS (Depth-First Search) are two important graph traversal algorithms. BFS uses a **Queue** and visits nodes level by level, while DFS uses a **Stack** and explores nodes as deeply as possible before backtracking. Both have a time complexity of **O(V + E)**.

## Conclusion

BFS and DFS are useful for exploring and analyzing graphs. BFS is commonly used for level-wise traversal and shortest paths in unweighted graphs, while DFS is useful for deep exploration, backtracking, and path-related problems. Understanding both algorithms is essential for learning graph-based problem solving.
