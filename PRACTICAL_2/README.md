# Practical-2: Searching Algorithms in C++

## Summary

In this practical, I implemented two searching algorithms in C++: **Linear Search** and **Binary Search**. Both programs take an array and a search element as input, find the required element, display its position if it exists, measure the execution time using the C++ `<chrono>` library, and show the time and space complexities.

During the implementation, I learned how each algorithm works:

- **Linear Search** checks each element one by one until the required element is found or the array ends. It can be used with both sorted and unsorted arrays.
- **Binary Search** works by repeatedly dividing a sorted array into two halves and searching only the relevant half. Since it reduces the search space at every step, it is much faster than Linear Search for large sorted arrays.

By comparing both algorithms, I understood their performance differences and how execution time and complexity affect their efficiency.

## Conclusion

This practical helped me understand the concepts of searching algorithms through hands-on implementation. I learned that **Linear Search** is simple and suitable for small or unsorted datasets, whereas **Binary Search** is faster and more efficient but requires the array to be sorted. Comparing their execution time, time complexity, and space complexity gave me a clear understanding of when each algorithm should be used. Overall, this practical improved my knowledge of searching techniques and their practical applications.
