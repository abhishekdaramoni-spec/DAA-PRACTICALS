## 📌 Summary

This project implements the **Matrix Chain Multiplication problem using Dynamic Programming** in C++. The algorithm determines the most efficient order for multiplying a sequence of matrices by minimizing the total number of scalar multiplications. A dynamic programming table is used to store previously calculated results and avoid repeated computations. The program also measures the execution time and displays the time and space complexity of the solution.

## ✅ Conclusion

The Matrix Chain Multiplication problem demonstrates how **Dynamic Programming** can efficiently solve optimization problems by using overlapping subproblems and optimal substructure. The implemented algorithm achieves a **time complexity of O(n³)** and a **space complexity of O(n²)**. By finding the optimal multiplication order, the program reduces unnecessary computational operations and provides an efficient solution compared with evaluating all possible multiplication orders.
